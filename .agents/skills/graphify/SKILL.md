# Graphify

Используйте этот skill для вопросов о структуре кодовой базы, модулях,
символах, связях, зависимостях и затронутых тестах. Он помогает сузить
контекст, но не заменяет чтение исходников.

## Начало работы

1. Прочитайте `AGENTS.md` и затем этот skill.
2. Если существует `graphify-out/graph.json`, проверьте свежесть:

   ```bash
   node scripts/graphify_index.mjs check
   ```

3. Если проверка вернула код `1`, либо индекса нет, пересоберите его:

   ```bash
   node scripts/graphify_index.mjs build
   ```

   Это запускает только AST-анализ `graphify update .`; не используйте
   `graphify extract` и не добавляйте индекс в Git.

Не считайте индекс актуальным только по наличию `graph.json`: проверка
сопоставляет `HEAD` и digest индексируемых файлов. Любое изменение или touch
таких файлов требует пересборки.

## Поиск

Начинайте с небольшого бюджета:

```bash
graphify query "where is position sizing computed" --budget 800
graphify explain "src/risk/risk-engine.mjs"
graphify path "src/domain/proposal.mjs" "src/risk/risk-engine.mjs"
graphify affected "src/domain/proposal.mjs" --depth 2
graphify god-nodes
```

- `query` находит кандидаты по вопросу; увеличивайте `--budget` только если
  результата недостаточно.
- `explain` раскрывает модуль или символ; используйте точные пути, когда имя
  неоднозначно.
- `path` показывает связь двух известных узлов.
- `affected` делает обратный обход для оценки зависимых модулей и тестов.
- Добавляйте `--graph`, только когда нужна форма связей.

После `affected` подтвердите кандидаты чтением imports и соответствующих
`test/**.test.mjs`. Не открывайте `GRAPH_REPORT.md` или крупные исходные файлы
целиком без необходимости; читайте узкие подтверждающие диапазоны строк.

## Границы достоверности

Для точных значений, формул, денег, размеров позиций, риск-инвариантов и
ветвлений всегда читайте исходники. Не выводите из графа разрешение сделки или
формулу размера позиции. Граф также не гарантирует отражение динамических
импортов, вызовов через строки, значений конфигурации и runtime-поведения.

Особая осторожность обязательна в `src/risk/**`, `src/execution/**` (включая
`live-guard.mjs`), `src/session/**`, `src/state/**`,
`src/reconciliation/**`, kill switch и `src/config/**`. Не ослабляйте
валидацию, risk controls, аудит или безопасность ради минимального изменения.
